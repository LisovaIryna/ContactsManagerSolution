# ContactsManagerSolution

## English

### Description
This project was created as part of an ASP.NET Core course on Udemy.
The application allows managing persons: adding, editing, deleting, and exporting persons list to different file formats. Compared to the previous version, this project was redesigned using Clean Architecture principles and includes authentication and authorization functionality.
The project was developed for educational purposes to practice working with ASP.NET Core, application architecture, and web development.

### Features
- User registration
- User authentication and authorization
- Add persons
- Edit persons
- Delete persons
- View persons list
- Export persons data to different file formats
- Layered architecture using Clean Architecture principles

### Technologies
- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- Razor Views
- HTML
- CSS
- JavaScript

### Architecture
The project is built using Clean Architecture principles to improve maintainability, scalability, and separation of concerns.
Entity Framework Core is used for database operations, and ASP.NET Core Identity is used for authentication and authorization.

### Project Status
Educational project created during a Udemy course.

### Notes
This project is a redesigned and extended version of the original ContactsManager application.

# Українська

## Опис
Цей проєкт був створений у рамках курсу з ASP.NET Core на Udemy.
Застосунок дозволяє керувати особами: додавати, редагувати, видаляти та експортувати список осіб у різні формати файлів. У порівнянні з попередньою версією, цей проєкт був перероблений з використанням принципів Clean Architecture та містить функціонал авторизації й автентифікації користувачів.
Проєкт розроблявся у навчальних цілях для практики роботи з ASP.NET Core, архітектурою застосунків та веброзробкою.

## Функціонал
- Реєстрація користувачів
- Авторизація та автентифікація користувачів
- Додавання осіб
- Редагування осіб
- Видалення осіб
- Перегляд списку осіб
- Експорт даних осіб у різні формати файлів
- Багатошарова архітектура з використанням принципів Clean Architecture

## Технології
- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- Razor Views
- HTML
- CSS
- JavaScript

## Архітектура
Проєкт побудований з використанням принципів Clean Architecture для покращення підтримуваності, масштабованості та розділення відповідальностей.
Для роботи з базою даних використовується Entity Framework Core, а для авторизації та автентифікації — ASP.NET Core Identity.
